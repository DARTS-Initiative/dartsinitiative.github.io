# Vibe Coding at DARTS Website

This website of the DARTS ecosystem have been developed following the **Vibe Coding** philosophy. This methodology uses Generative Artificial Intelligence under the strict direction of a human to accelerate development without compromising technical vision or quality.

## Creator Guidelines

The use of AI in this project is not arbitrary; it follows the guidelines set by the creator and is used exclusively as an acceleration tool. The intent, architecture, and critical decisions **always reside with the human**.

## Vibe Coding Norms at DARTS

To ensure the project maintains its integrity and purpose, we follow certain norms when creating with Vibe Coding:

1.  **Preservation of Intent**: AI acts as an expert "pair of hands," but the "brain" and direction of the project are human. Every line of generated code is reviewed to ensure it meets the "vibe" and the original intent.
2.  **Transparency**: We document the use of these tools to be honest with the community and foster a modern and efficient development culture.
3.  **Quality over Speed**: Although AI allows us to go faster, the priority remains maintainability, clean code, and robust functionality.
4.  **Continuous Evolution**: The project's "vibe" evolves. We adjust our interactions with AI so they are always aligned with the current state of technology and DARTS' goals.
