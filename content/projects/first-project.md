# Autonomous Drone Swarm

This project explores the capabilities of decentralized algorithms in managing large-scale drone swarms.

## Key Features

- **Decentralization**: No single point of failure.
- **Scalability**: Works with 10 to 1000 drones.
- **Resilience**: Adaptive to node loss.

## Status

Currently in the simulation phase, moving to hardware testing soon.
